# Assignment 1 - FS Model for Node

This project includes:
- React UI with college logo, heading, textbox, and two buttons.
- Node/Express API that writes and reads a file using the File System module.

## Run the server

1. Open a terminal in `assignment1/server`
2. Install dependencies:
   - `npm install`
3. Start server:
   - `npm start`

Server runs at http://localhost:4000

## Run the client

1. Open a terminal in `assignment1/client`
2. Install dependencies:
   - `npm install`
3. Start client:
   - `npm run dev`

Client runs at http://localhost:5173

## Notes
